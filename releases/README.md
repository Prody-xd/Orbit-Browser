# Descargas

Instalador de Windows (NSIS), listo para usar:

- [Orbit-Browser-Setup-0.1.0.exe](./Orbit-Browser-Setup-0.1.0.exe)

Al instalarlo crea accesos directos en el escritorio y en el menú Inicio. Windows puede avisar que no está firmado: elige «más información» y ejecutar.

La carpeta portable `dist/win-unpacked` no está aquí: pesa más de 300 MB y GitHub no admite esos archivos en el repositorio. Si la necesitas, genérala en local con `npm run dist`.
